ChatMCP Studio 1.3.0 / Browser Companion 1.4.0
================================================

MỤC TIÊU
- Hội thoại agent được lưu liên tục, nhiều prompt trong cùng phiên, không
  tạo chat mới sau khi ngắt mạng hoặc bấm dừng (trừ khi người dùng chủ động).
- Dashboard IDE dark layout với sidebar lịch sử, cuộc hội thoại nối tiếp,
  timeline sự kiện/công cụ, trạng thái và checkpoints.
- Sửa sự nhầm lẫn giữa số gói hội thoại, phản hồi AI và lời gọi công cụ MCP.

THAY ĐỔI QUAN TRỌNG
- POST /api/tasks/continue tiếp tục cùng ID Web/API; POST /api/tasks/delete
  chỉ xóa dữ liệu phiên trong Hub sau khi người dùng xác nhận.
- BrowserRunner giữ prompts, runs, lastIssuedTurn, chatUrl, checkpoint và
  metadata thao tác chưa xác minh; khôi phục từ crash thành trạng thái paused.
- Companion mở đúng URL chat cũ, không tự mở chat home để tiếp tục. Xử lý
  journal cũ failed/reconciling và thay instance ID sau khi Hub restart.
- Reattach chỉ cho gói đầu tiên của follow-up do người dùng cho phép;
  các gói tiếp theo vẫn xác minh thứ tự và tab.
- API agent dựng lại ngữ cảnh công khai từ phiên đã lưu; không lặp lại thao tác
  ghi/xóa file khi chưa rõ kết quả.
- Sidebar hiển thị đầy đủ danh sách session đã lưu, không cắt ở 50/60,
  cập nhật lần chạy mới nhất; đọc chi tiết theo yêu cầu để nhẹ hơn.
- README và SESSION-RECOVERY.md hướng dẫn sao lưu lịch sử, khôi phục,
  phân biệt số gói với số phản hồi.

GIỚI HẠN
- Không tự phục hồi được hội thoại ChatGPT Web nếu chat đã bị xóa hoặc không
  lưu được URL chính thức. Không tự phát lại lệnh ghi/xóa MCP chưa xác minh.
- Tự hồi phục ngắt mạng ngắn yêu cầu Hub + trình duyệt/Companion còn hoạt động.
  Sau reboot hay Stop dùng sidebar chọn phiên cũ và gửi prompt Tiếp tục.
- API mode không có provider-native conversation token; nó dựng lại ngữ cảnh
  từ checkpoint công khai. Không lưu suy luận nội bộ model.
- Các kiểm thử tự động dùng mock/local HTTP; chưa xác minh trên máy Edge,
  Windows/DPAPI, API gateway của người dùng.

NÂNG CẤP
1. STOP-CHATMCP-HUB.cmd.
2. Giải nén, ghi đè code trong thư mục CHATMCP-HUB hiện tại. TUYỆT ĐỐI KHÔNG
   XÓA deploy\.generated\chatmcp-hub: đây là nơi lưu phiên và API config.
3. edge://extensions -> Reload ChatMCP Hub Companion 1.4.0.
4. START-CHATMCP-HUB.cmd, mở http://127.0.0.1:3007.
5. Chọn phiên cũ trong sidebar; nhập prompt 'Tiếp tục hoàn thành bài lab'.
