PENDING NOTICES

 - The Rust standard library inside rg.exe (item 17). ripgrep's release workflow builds with the nightly toolchain of the day, which neither the
   workflow nor the archive pins, so its version and exact texts are not named here and not in the repository yet.
 - The static Microsoft C runtime that rg.exe is also linked with (ripgrep's .cargo/config.toml sets +crt-static for this target): its terms belong
   with the Visual C++ runtime terms of item 3.
 - Items 3, 9, 11, 12, 13 and 15 above. A build that lacks the Tree-sitter grammar notices carries licenses/PENDING-NOTICES.txt and lists them in
   runtime-manifest.json ("pendingNotices"); only builds that are not releases may be made that way.
 - The Browser Companion archive ChatMCP-Browser-Companion.zip does not contain LICENSE or NOTICE yet.

NOT REDISTRIBUTED

 - Git for Windows (GPL-2.0), Microsoft Edge or Chromium, the Microsoft Edge WebView2 Runtime, Ollama, LM Studio and model-provider services are
   separate installations that the user provides.
 - node-pty (MIT) is optional and installed by the user from npm on request.
 - Build-time and test-only dependencies (Vite, Tailwind CSS, type packages, the Playwright test runner, lightningcss, caniuse-lite) are not in the installer.
 - Agent Skills that the user imports keep their own licenses; a public repository does not by itself grant redistribution permission.

EARLIER RELEASES

 The Cloud Harness server, the Desktop Commander runtime and the MCP SuperAssistant proxy of the 1.x and 2.x releases are not installed,
 started or included by the current local-only Hub. Their notes remain in Git history.
