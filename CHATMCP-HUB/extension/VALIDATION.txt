LIMITATIONS OF VALIDATION
This is unit/DOM integration with mocked Chrome APIs, not an installed
Chrome/Edge extension running in the user's actual ChatGPT account or on
Windows. It does not prove selectors match every ChatGPT experiment or that
a background tab always exposes idle/author state. The real DOM route may
stop with a precise unknown-interface/login/quota error. Native CSP, rendering,
service-worker scheduling and browser background throttling are not emulated.
No real MCP call is made by these extension tests. Backend/MCP integration is
documented separately in the Hub validation. Browser image/audio attachment
conversion is not implemented; tool output is transported as text.
