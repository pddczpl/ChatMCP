CHAT-MCP STUDIO 2.0.0 — RELEASE NOTES (10/10/2026)
Companion 1.4.0 (unchanged)

New features implemented in the bundle:
- IDE-like dark UI with Explorer, source text viewer/editor, safe text-only preview, Git review/restore, terminal, plan, skills and read-only API research subagents.
- Local codebase search (filename/text/symbol) with bounded mtime/size cache.
- Git status/diff/diff --check and selective SHA-guarded review / restore from partial checkpoint snapshots. Preserve unrelated changes.
- Permission gate on verified live MCP calls with three modes (review/manual/autonomous), per-call approvals and persisted decisions. Dangerous operations and shell continue to require approval.
- Durable per-conversation plan, tool/checkpoint journal, and a limited tool-verification counter. Model can discover studio.* tools in the complete original MCP catalog.
- Explicit opt-in safe auto-resume after Hub restart for interrupted conversation sessions (same ID, same official Web URL), never on unverified tool/delivery outcomes. Networking retry remains from v1.1.6; manual follow-up on same session remains from v1.3.0.
- Subagent API research requests limited to three parallel read-only workers; persists results.

Notes & safety:
- Terminal and external MCP commands are NOT isolated OS sandbox. They run with user's Windows account rights; review before approval.
- Backups are bounded text-only partial snapshots; changes outside snapshot cannot be automatically restored. Git diff and checkpoint differ from staging/committing.
- Preview shows text; there is no live GUI app preview or embedded full language server yet.
- Tool calls and prompt histories are durable after acknowledgement. External side effects whose results are missing are never blindly retried.
- Browser mode needs Companion, a stable URL and matching task/turn/nonce; the DOM may change and fail closed.
- This release has NOT undergone end-to-end validation on the user's Windows/Edge/gateway. See TEST-RESULTS-2.0.0.txt.

Install: STOP-CHATMCP-HUB.cmd -> backup state -> unzip into parent ChatMCP dir -> reload Companion 1.4.0 -> START-CHATMCP-HUB.cmd. See UPGRADE-2.0.0.md.
