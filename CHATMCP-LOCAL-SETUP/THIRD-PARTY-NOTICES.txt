ChatMCP Hub 1.0.0 — integration notes
Prepared 2026-10-09 for the user's existing Windows installation.

This bundle contains the Hub integration source and an optional browser
companion. It does not include Docker Desktop, Node.js, the Cloud Harness
repository, node_modules, user credentials, a preconfigured AI account,
or the MCP SuperAssistant extension itself.

Runtime dependencies installed or reused by the Hub:

1. @wonderwhy-er/desktop-commander 0.2.52
   https://github.com/wonderwhy-er/DesktopCommanderMCP
   Installed under deploy/.generated/desktop-commander-local.

2. @srbhptl39/mcp-superassistant-proxy 0.1.8
   https://github.com/srbhptl39/MCP-SuperAssistant
   Installed under deploy/.generated/browser-proxy-compat.
   The Hub loads this package through its compatibility adapter. It does not
   overwrite the upstream package source on disk.

3. @modelcontextprotocol/sdk
   https://github.com/modelcontextprotocol/typescript-sdk
   Resolved from the installed Desktop Commander dependency tree. The SDK's
   exact transitive version is determined by the installed package lock.

4. Existing bestagentkits/cloud-harness-mcp deployment
   https://github.com/bestagentkits/cloud-harness-mcp
   Version and configuration remain those installed by the user. The Hub
   discovers its current tool catalog rather than asserting a fixed count.

All third-party packages and their transitive dependencies retain their own
licenses, notices and terms. npm installs their distributed license files;
consult those files and the original repositories when redistributing them.
Pinned top-level package versions do not pin every transitive dependency
on a new installation. Keep the generated package-lock files to reproduce
the dependency tree that succeeds on your machine.

Optional companion behavior was checked against MCP SuperAssistant source:
https://github.com/srbhptl39/MCP-SuperAssistant/tree/c26168ee2c5708a3a65ef5afd88cda1a97c81734
See extension/HUONG-DAN.txt for the referenced source paths and limitations.

OpenAI, ChatGPT, Codex, Docker, Microsoft, VS Code, and upstream project names
identify their respective products. This user-specific integration is not
presented as an official product or supported distribution of those projects.
