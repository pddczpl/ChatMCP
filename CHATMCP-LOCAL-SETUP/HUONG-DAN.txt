DU LIEU VA CAU HINH
- Giu entry cloud-harness, bearer token va cac server khac trong
  deploy\.generated\mcp-client.proxy.json.
- Them entry desktop-commander dung node.exe da resolve dung MOT duong dan.
- Package va launcher nam tai deploy\.generated\desktop-commander-local.
- cwd cua Desktop Commander la thu muc bai lab; nen van dung duong dan tuyet doi.
- allowedDirectories duoc dat bang tool set_config_value chinh thuc va doc lai.
- Cac API file duoc gioi han vao thu muc bai lab. Terminal van chay theo quyen
  tai khoan Windows; allowedDirectories khong phai sandbox cho lenh terminal.
- Desktop Commander dung chung config theo Windows user tai
  %USERPROFILE%\.claude-server-commander\config.json. Neu da dung server nay
  trong client khac, pham vi API file o client do cung doi sang thu muc bai lab.
- Giu cac setting Desktop Commander khac; backup config cu truoc khi khoi dong.
- Script chi doc thu muc de kiem tra. Khong sua bai lab, cai Python/pip,
  chay test bai lab, commit, push hay thay doi ExecutionPolicy.
- Desktop Commander cung cap file + terminal tools; khong phai tool bam
  chuot/ban phim trong VS Code. VS Code se nhin thay file cung thu muc da sua.

NEU THIET LAP DUNG
Gui cac dong [MCP-LOCAL] va loi npm da duoc script loc.
Khong gui noi dung mcp-client.proxy.json hay file .bak vi co key.

Neu dang cai ma phai dung giua chung: chay lai script; no kiem tra package
