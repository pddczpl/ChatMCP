Manual tests reuse the inspected upstream JSON parser and functionBlock
renderer at c26168ee2c5708a3a65ef5afd88cda1a97c81734 in a LinkeDOM fixture.
They verify no-argument calls, typed arguments and escapes, one-call parsing,
partial content, source preservation, native-pre/card guards, duplicate
clicks, React replacement, changed payloads, route changes and large inputs.

Automatic tests verify default OFF; explicit opt-in; assistant-only ancestry;
user/tool/system/unknown and contradictory-role rejection; quote/editor/result
exclusions; fresh session IDs; history exclusion; complete-call + idle gates;
visible Stop veto; no clicks on Send/Stop/Run/Allow; cancellation of an armed
timer; role recheck during stabilization; deduplication and route disarming.
Each automatic call checks current Hub readiness, workspace path, generation
and process instance. Tests cover each mismatch, offline state, repeated
checks and invalidation of an in-flight response when the user disables Auto.
Composer tests preserve nonempty drafts, reject unknown editors and populate
only an empty supported editor via its editing API without submitting.

Popup tests mock Chrome messaging and the two fixed GET endpoints. They
verify limited Hub state, prefix substitution, opt-in, prepare-only behavior,
manual mode, copy fallback and offline state. Background tests verify trusted
top-frame ChatGPT senders only, a fixed GET endpoint, rejection of other
sites/extensions/frames, whitelisted response fields and offline/malformed
state. Manifest has one fixed loopback host permission and isolated scripts.

LIMITATIONS OF VALIDATION
These are DOM/unit integration fixtures, not a loaded Chrome/Edge extension
or an end-to-end Windows + local Hub + ChatGPT + MCP session. Geometry,
timers, theme, history and native execute transport are controlled stubs.
No real MCP tool was called by these tests. Existing manual v1.1 behavior had
been confirmed by the user; the new opt-in automation still depends on actual
author/idle attributes being exposed by their ChatGPT DOM variant.
