TEST ENVIRONMENT LIMITATIONS:
- Chromium is policy-blocked from local HTTP even on loopback in this build environment, so UI used mocked fetch. Node backend HTTP is tested independently using actual bound loopback sockets. Browser-to-Hub HTTP was NOT tested together in a real browser.
- No live Windows/Edge, Docker Desktop, Realtek LAN disconnect, external Cloudflare tunnel, actual ChatGPT DOM, actual Gemini gateway credential, or actual user workspace changes were exercised.
- Tests do not prove production-grade isolation, durable subprocess execution across power loss, or parity with Codex/Antigravity/Claude Code.
- Auth/permission gate is application-level, not an OS sandbox. Terminal and Desktop Commander inherit Windows user permissions.
- React 16.0.0 / ReactDOM 16.0.1 assets are intentionally bundled offline but old and should be upgraded with a reproducible dependency build for production use.
