MICROSOFT C/C++ RUNTIME COMPONENTS

 Two places carry code of Microsoft's C and C++ runtime; both are redistributed unmodified and neither is DatGold's own work. THIRD-PARTY-NOTICES.md has
 the same text with the links, under the heading "Microsoft C/C++ runtime components".
 - Inside rg.exe, linked statically: ripgrep's .cargo/config.toml sets +crt-static for x86_64-pc-windows-msvc, so rg.exe contains libcmt.lib and
   libvcruntime.lib (from the MSVC toolset of Visual Studio) and libucrt.lib (from the Windows SDK). The installer build checks that the import table of
   rg.exe names no C runtime DLL (VCRUNTIME140.dll, MSVCP140.dll, UCRTBASE.dll, api-ms-win-crt-*).
 - Inside the CPython archive, as DLLs: vcruntime140.dll and vcruntime140_1.dll (Visual C++ 2015-2022 runtime), as the Python Software Foundation ships them.
 What Microsoft publishes, read on 2026-10-25 (the text of these terms is not reproduced here):
 - Windows SDK license terms, section "Distributable Code", and its REDIST.TXT list (learn.microsoft.com/en-us/legal/windows-sdk/redist, updated 2024-10-21):
   the section "Static LIB files" says that the .lib files under Lib\<version>\ucrt\<arch> (and um\<arch>) may be distributed unmodified when built as part
   of your program.
 - Visual Studio 2022 and 2026 license terms (visualstudio.microsoft.com/license-terms/), section "Distributable Code", and their Distributable Lists
   (learn.microsoft.com/en-us/visualstudio/releases/2022/redistribution and .../2026/redistribution, both dated 2025-11-11): they name the Visual C++
   runtime merge modules and the files under VC\redist (where vcruntime140.dll is); they do not name libcmt.lib or libvcruntime.lib.
 - "Redistribute Visual C++ Files" (learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files, ms.date 2026-04-13): distribution of the
   redistributable package, merge modules and individual binaries is limited to licensed Visual Studio users and subject to the Microsoft Software License Terms.
 Conditions for Distributable Code: significant primary functionality of the program; distributors and external end users must agree to terms that protect the
 code at least as much as the license; the licensee indemnifies Microsoft; for a .lib (SDK): only the result of linking it into a program, and a valid copyright
 notice on the program.
 What that means here: DatGold redistributes rg.exe (built by the release workflow of ripgrep) and the CPython runtime (built by the Python Software Foundation)
 unmodified. Its installer shows no end-user agreement and DatGold gives Microsoft no indemnity, so nothing in this repository meets the condition about terms for
 end users or the indemnity condition. Whether these conditions bind DatGold as a redistributor, whether code linked statically from libcmt.lib and libvcruntime.lib
 is Distributable Code at all, and whether the licenses of ripgrep and CPython count as terms that protect Microsoft's code are legal questions that this file
 does not answer. This is an inventory kept by the maintainers, not legal advice.
