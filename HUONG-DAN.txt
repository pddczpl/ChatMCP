CHATMCP STUDIO — HƯỚNG DẪN LOCAL-ONLY

Lưu ý: từ nhánh refactor/local-only-remove-cloud, DatGold chỉ chạy cục bộ
trên Windows (127.0.0.1). Không cần và không còn hỗ trợ Cloud Harness MCP,
Docker/Render hosting, proxy cổng 3006 hoặc đăng nhập chủ sở hữu server.

1. CÀI VÀ KHỞI ĐỘNG
   - Với bản phát hành: lấy DatGoldSetup.exe (bản đến v3.10.2 tên là ChatMCPSetup.exe) từ trang GitHub Releases;
     so sánh SHA-256 với checksum được phát hành, cài và mở DatGold Studio.
   - Với mã nguồn: cài Git for Windows, Node.js 22.12+ và npm; mở PowerShell
     trong thư mục repository:
       npm ci --prefix .\DATGOLD-HUB\ui
       npm run build --prefix .\DATGOLD-HUB\ui
       .\START-CHATMCP-DESKTOP.cmd
   - Hoặc chạy web dashboard trên chính máy của bạn:
       .\DATGOLD-HUB\START-CHATMCP-HUB.cmd -ProjectPath 'C:\Projects\Demo'
     Mặc định truy cập http://127.0.0.1:3007.

2. CHỌN MODEL
   - Cấu hình OpenAI, Gemini, Anthropic hoặc API tương thích do bạn sử dụng.
   - Với mô hình local: dùng Ollama/LM Studio ở địa chỉ loopback và chọn
     model có hỗ trợ function/tool calling.
   - Local-only không có nghĩa offline-only: API model, GitHub và tìm kiếm
     có thể dùng Internet khi bạn chủ động sử dụng.

3. CODE VÀ MULTI-AGENT
   - Chọn thư mục workspace Git, mặc định dùng chế độ Review.
   - Tab Tác nhân hiện công việc nền: các task và subagent mà agent giao
     trong lúc bạn trò chuyện, kèm nút dừng từng task.
   - Worktrees không phải Windows Sandbox/AppContainer; lệnh được duyệt
     vẫn có thể chạy với quyền tài khoản Windows hiện tại.

4. SKILLS HUB
   - Mở tab Skills, chọn các nguồn GitHub đáng tin, refresh và xem revision.
   - SKILL.md/tài nguyên được ghi hash; third-party skills mặc định tắt.
     Không chạy script đã tải khi chưa kiểm tra nội dung và quyền sử dụng.

5. DỪNG VÀ KIỂM TRA
   - Dừng Hub qua STOP-CHATMCP-HUB.cmd.
   - Dữ liệu riêng tư nằm ở %LOCALAPPDATA%\ChatMCP\hub; sao lưu trước khi
     xóa hoặc thử một bản build khác.
   - Không đặt CHATMCP_PUBLIC=1 hoặc truyền --backend mcp/--repo-root.
