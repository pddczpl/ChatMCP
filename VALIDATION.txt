BRIDGE COVERAGE
- A complete no-argument workspace_list call creates no input pre/card
  until its transfer button is clicked.
- The native renderer then creates one function-block and one Run stub;
  the test records zero Run clicks or tool executions.
- The original wrapper HTML, code and controls stay unchanged.
- Canonical JSONL preserves typed parameters, escaping, braces in strings,
  Windows paths, nested arrays/objects, embedded newlines, quotes and <>&.
- Pretty JSON, syntax-highlighted spans and adjacent line divs normalize.
- Code examples in user/document content are never automatically imported.
- Incomplete strings/events, extra prose, invalid JSON, mismatched/missing
  IDs, reversed events, multiple calls, unknown events/fields, duplicate
  parameters/descriptions and invalid description types are rejected.
- Unsupported top-level null parameters, prototype/hasOwnProperty keys
  and nonfinite nested numbers are rejected.
- An invalid non-string event type cannot stop the scan with a coercion
  exception. A within-limit large array does not trigger an argument-limit
  exception during numeric validation.
- Existing native pre and actual native-card relations prevent a duplicate
  normalized copy. A pre marker alone is not reported as a successful card.
- Repeated clicks and identical payloads share a single imported card.
  Different calls with the same call_id remain distinct.
- Source changes invalidate the old display and require a new click.
  A last-moment source change cannot import a stale/unreviewed payload.
- A removed imported host is not reattached or recreated.
  Recreated source wrappers retain the consumed-payload record.
- Streaming content becomes eligible without automatic import.
- Repeated script loading and 100 unrelated DOM mutations do not recurse.
- A different pathname permits a new explicit import with the old display
  invalidated.
